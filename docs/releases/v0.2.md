타이틀 로고 영상의 조립 장면까지 한글 로고로 바꾸고, 번역을 원문과 다시 대조해 다듬었습니다.

**원본 일본판 게임 파일(content/Pack)에 적용하는 패처입니다.**

## 변경 사항

- 타이틀 로고 영상의 조립 장면(시작 후 약 1~3초)도 한글 로고로 바꿨습니다.
- 원문과 대조해 대사 몇 줄의 번역을 다듬었습니다.
- 스킬 이름(「어깨너머 성장」 등)·인물 이름·아이템 이름과 설명, 메뉴 도움말 몇 곳의 번역을 원문에 맞게 고쳤습니다.
- 띄어쓰기 95곳을 바로잡았습니다.
- 전투 화면 아래 도움말(HELP)에서 스킬·아이템 설명의 낱말이 줄바꿈 자리에서 붙어 보이던 문제를 고쳤습니다.

## 배포 파일

| 파일 | 필수 | 설명 |
|---|---|---|
| `ASEJ_KPatch_v0.2.zip` | ○ | 한글 패처. 사용자 설명서 포함 |
| `TMS_KO_v0.1_Movies.zip` | 선택 | 동영상 자막(약 3.4GB). v0.1과 같은 파일이라 이미 받았다면 다시 받을 필요가 없습니다. [구글 드라이브](https://drive.google.com/file/d/16qqc3NX-3AZecIR2Mo_DmEXbTtlPON5z/view?usp=drive_link)에서 받아 패처와 같은 곳에 풀면 함께 적용 |
| `README_KO.txt` | | 사용자 설명서 |

## 적용 방법

1. `ASEJ_KPatch_v0.2.zip`을 풀고, 동영상 자막을 넣으려면 `TMS_KO_v0.1_Movies.zip`도 같은 곳에 풉니다(v0.1 때 풀어 둔 `TMS_KO_v0.1` 폴더가 옆에 있으면 그대로 쓰입니다).
2. 게임 폴더(또는 `content\Pack` 폴더)를 `ASEJ_KPatch_v0.2\패치하기.bat` 위에 끌어다 놓습니다.
3. `출력\sdcafiine`은 SD 카드 `wiiu\sdcafiine\`에, `출력\cemu\TMS_Korean`은 Cemu `graphicPacks`에 넣습니다.

패처는 원본 일본판 파일에 적용합니다. v0.1을 적용한 파일에는 적용할 수 없으니 원본 파일을 넣어 주세요. 오류 메시지와 해결 방법은 동봉한 `README_KO.txt`를 참고하세요.
