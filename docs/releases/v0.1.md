첫 시험판입니다. 대사 전체와 글씨가 그려진 그림·이펙트, 타이틀 로고 영상을 한글화했습니다.

**원본 일본판 게임 파일(content/Pack)에 적용하는 패처입니다.**

## 변경 사항

- 대사 전체(28,399개 메시지)를 한글화하고, 게임 폰트 10종에 한글을 새로 그려 넣었습니다.
- 글씨가 그려진 그림 259장과 이펙트 그림 26장, 타이틀 로고 영상을 한글화했습니다.
- 이벤트 동영상 21편에 한글 자막을 넣었습니다(선택 패치).

## 배포 파일

| 파일 | 필수 | 설명 |
|---|---|---|
| `TMS_KO_v0.1_Patcher.zip` | ○ | 한글 패처. 사용자 설명서 포함 |
| `TMS_KO_v0.1_Movies.zip` | 선택 | 동영상 자막(약 3.4GB). [구글 드라이브](https://drive.google.com/file/d/16qqc3NX-3AZecIR2Mo_DmEXbTtlPON5z/view?usp=drive_link)에서 받아 패처와 같은 곳에 풀면 함께 적용 |
| `README_KO.txt` | | 사용자 설명서 |

## 적용 방법

1. `Patcher.zip`을 풀고, 동영상 자막을 넣으려면 `Movies.zip`도 같은 곳에 풉니다.
2. 게임 폴더(또는 `content\Pack` 폴더)를 `패치하기.bat` 위에 끌어다 놓습니다.
3. `출력\sdcafiine`은 SD 카드 `wiiu\sdcafiine\`에, `출력\cemu\TMS_Korean`은 Cemu `graphicPacks`에 넣습니다.

패처가 원본과 결과의 해시를 검사합니다. 오류 메시지와 해결 방법은 동봉한 `README_KO.txt`를 참고하세요.
